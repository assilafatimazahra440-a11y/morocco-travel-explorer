# Morocco Travel Explorer

A responsive web application that allows users to explore Moroccan cities, search destinations, filter by region, and view detailed information including landmarks, history, events, and maps.

## Features
- Search cities by name
- Filter cities by region
- Dynamic data loading from JSON
- Interactive modal with image gallery
- Links to Google Maps and Wikipedia
- Responsive modern design

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- JSON
- Fetch API

## Installation
1. Clone the repository
2. Open `index.html` in your browser
